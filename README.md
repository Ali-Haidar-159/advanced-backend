
#  Advanced Backend Development

This repository contains my backend development practice projects using **Node.js, Express.js, MongoDB, Prisma and other backend technologies**.

I created these projects to learn, practice, and strengthen my understanding of backend development, including middleware, file uploads, database operations, streaming, and application architecture.

## ️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Ali-Haidar-159/advanced-backend
```

### 2. Navigate to the Project Directory

```bash
cd Advanced-Backend
```

### 3. Navigate to Your Desired Project

Each folder contains a separate practice project.

For example:

```bash
cd middleware
```

### 4. Install Dependencies

```bash
npm install
```

### 5. Configure Environment Variables

If the project requires environment variables, create a `.env` file using `.env.example`.

```bash
cp .env.example .env
```

For Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Update the environment variables with your own credentials.

### 6. Run the Project

```bash
npm start
```

**Note:** Each project may have different dependencies, environment variables, and scripts. Check its `package.json` for specific instructions.
